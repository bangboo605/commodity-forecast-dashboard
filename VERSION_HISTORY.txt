원자재 가격 대시보드 버전 기록
================================

이 파일은 각 버전에서 최종적으로 제공하는 기능과 개선 결과를 기록합니다.
구현 과정, 반복 조정, 예비파일 생성 내역은 기록하지 않습니다.

[기록 구분]
- 기능 업데이트: 새로운 화면, 데이터 구조, 로직처럼 사용 방식이 달라진 변경
- 개선·수정 패치: 기존 기능의 디자인, 문구, 속도, 오류를 개선한 결과
- 현재 공식 버전: item_selection_v3.8.py


[버전 목차]

Version 1.x — 품목 선택과 주요 변수 시나리오 설정
- 1.0: 품목 선택 화면 구축
- 1.1: 주요 변수 설정·예측시점 조회·시나리오 데이터 표 화면 제공
- 1.2: 분기별 단일 선택 셀 그리드와 commit 시 final 반영 구현
- 1.3: 주요 변수별 세부 항목 드롭다운과 순차 이동 제공
- 1.4: 과거 데이터와 committed final을 연결한 그래프 제공
- 1.5: 주요 변수 commit 여부 일괄 검사와 미완료 자동 안내
- 1.6: 시나리오 값 가져오기와 final 직접 입력·commit 기능 제공
- 1.7: 데이터 세트 1·2·3 선택 기능 제공
- 1.8: 예측시점 월별 확장과 행 버튼 그래프 강조 제공
- 1.9: 데이터 표·그래프 예측 구간 5개 분기 확장, 과거 기간 선택 제공

Version 2.x — 품목 가격 예측과 결과 비교
- 2.0: 품목 가격 예측 단계와 원클릭 설정 구현
- 2.1: 주요 변수 전망과 가격 전망을 나란히 비교하는 결과 화면 구축
- 2.2: 데이터셋 저장·이름 변경·삭제·복수 강조 및 교차 시점 비교 구현

Version 3.x — 실제 데이터 기반의 품목별 동적 대시보드
- 3.0: 금 실제 주요 변수 데이터 연결과 금 전용 화면 구축
- 3.1: CSV 컬럼에 따른 동적 주요 변수 구성과 품목별 가격 예측 결과 기반 마련
- 3.2: 은 품목 추가, 품목별 예측 분기 수(가격 전망 포함) 가변화
- 3.3: 외부 제공 회귀계수(로그 변환)로 금 가격을 실시간 계산해 가격 전망·데이터셋 비교에 연결, 비교 그래프 강조·순서 일관성 개선
- 3.4: 가격 예측 결과 화면 진입 흐름의 자동 스크롤 개선, 좁은 화면 반응형 레이아웃 정비
- 3.5: 금 가격 전망을 검증된 TVP(시변계수) 회귀 모델 기반 실시간 계산으로 전환 (archive/versions)
- 3.6: 금 가격 전망에 과거 예측시점 기반 백테스트(실제가 vs 예측가) 지원, 시변계수를 예측시점 기준으로 적용, TVP 모델을 예측시점 직전까지의 데이터로 학습하고 다단계 예측 내내 시변계수가 계속 진화하도록 개선
- 3.7: 금 시나리오 데이터의 base를 실제값 ±1% 랜덤값으로, high·low를 base ±10%로 단순화, 예측시점 선택 범위를 2023-04~2024-06 월별로 변경, final ±10% 일괄 조정 버튼 추가
- 3.8: 금 시나리오를 12시리즈 변수별 선정 모델의 예측시점별 예측(low 5%·base 50%·high 95%)으로 교체, 예측시점을 2020Q1~2026Q1 분기별 25개로 변경, 예측 4개 분기

※ 아래에는 각 버전의 기능 업데이트와 개선·수정 패치를 상세히 기록합니다.

[기능 업데이트]

[Version 1.2]
파일명: item_selection_v1.2.py

[기능 업데이트]
- 분기마다 base·high·low 중 하나만 선택할 수 있는 셀 그리드 제공
- 같은 분기의 다른 셀을 선택하면 기존 선택을 자동 해제
- 모든 분기를 선택한 뒤 commit하면 선택값을 분리된 final 영역에 반영
- 주요 변수와 예측시점별 선택 및 final 상태를 독립적으로 관리

[개선·수정 패치]
- 선택 셀과 final을 저채도 청록색으로 표시
- 예측시점을 YYYY-MM-DD 형식으로 표시하고 날짜가 속한 분기부터 4개 분기 계산
- commit 경고창을 버튼 왼쪽에 배치하고 버튼과 동일한 높이로 통일
- 데이터가 없는 분기는 빈값으로 표시


[Version 1.3]
파일명: item_selection_v1.3.py

[기능 업데이트]
- 주요 변수별 세부 항목 드롭다운 제공
- 다음 버튼으로 수요부터 거시경제까지 주요 변수를 순서대로 이동
- 마지막 주요 변수에서는 완료 위치를 안내

[개선·수정 패치]
- 주요 변수 안내창과 commit 경고창의 디자인 통일
- 좁은 화면에서는 안내창이 다음 줄로 이동하는 반응형 배치 적용
- 데이터 셀 클릭을 방해하던 도움말 툴팁 제거


[Version 1.4]
파일명: item_selection_v1.4.py

[기능 업데이트]
- 예측시점 이전 4개 분기의 base와 이후 4개 분기의 committed final을 연결한 그래프 제공
- 과거 데이터는 진한 실선, final은 붉은 점선과 포인트로 구분
- 예측 시작 분기에 세로 점선 표시
- commit이 완료된 경우에만 그래프의 예측 구간 갱신

[개선·수정 패치]
- 셀 선택 콜백과 그래프 캐싱을 적용해 반응 속도 개선
- 품목 적용 직후 주요 변수가 선택되지 않은 빈 초기 상태 제공
- 주요 변수 미선택 시 그래프·표를 비우고 선택 안내 표시
- X축의 전체 분기 라벨과 final 예측 포인트 표시
- 품목 선택 버튼과 현재 품목 카드의 세로 위치 정렬


[Version 1.5]
파일명: item_selection_v1.5.py

[기능 업데이트]
- 5개 주요 변수의 final commit 완료 여부를 한 번에 검사
- commit되지 않은 변수를 안내하고 가장 앞선 미완료 변수로 자동 이동
- final과 다른 미커밋 선택을 호박색으로 구분

[개선·수정 패치]
- 전기동만 적용 가능하며 미지원 품목에는 준비 중 안내 표시
- 품목 및 commit 경고창을 연한 노란색 스타일로 통일
- 미커밋 변경 안내를 일반 commit 누락 안내보다 우선 처리


[Version 1.6]
파일명: item_selection_v1.6.py

[기능 업데이트]
- 선택한 시나리오 값을 final 초안으로 가져오는 기능 제공
- final 값을 분기별로 직접 입력하고 별도 commit 가능
- commit된 final만 그래프에 반영
- final이 commit 값과 다르면 호박색, 같으면 청회색으로 표시
- 수동 입력으로 시나리오 원본과 달라지면 해당 셀 선택을 해제하고 원래 값으로 복원하면 다시 연결

[개선·수정 패치]
- 주요 변수 미선택 시 final 입력과 가져오기·commit 조작 차단
- 그래프 소제목을 중앙 정렬하고 중복 Y축 제목 제거
- 선택된 분기만 final에 부분 반영하고 기존 수동 입력값 유지
- 빈 final은 0이 아닌 미입력 상태와 대시(—)로 표시
- 사용자가 직접 입력한 숫자 0은 정상 데이터로 인정

- 기본 상태와 commit 직후에는 final을 강조
- 행 버튼에 그래프 계열별 색상을 적용


[Version 1.9]
파일명: item_selection_v1.9.py

- base·high·low 색상을 파랑·마젠타·노랑으로 구분


[Version 2.0]
파일명: item_selection_v2.0.py

[기능 업데이트]
- 5개 주요 변수의 현재 데이터 세트별 final 완료 여부를 검사하는 품목 가격 예측 기능 제공
- 예측시점·데이터 세트·시나리오 값을 자동 설정하고 모든 변수를 commit하는 원클릭 설정 제공
- 90·L1·L2·P1·P2 중 하나의 예측 계열을 사용한 품목 가격 예측 그래프 제공
- 실제가 기준 과거 1년·2년·3년과 예측시점 포함 5개 분기 표시
- 모든 조건이 완료되면 가격 예측 결과 단계로 자동 이동

[개선·수정 패치]
- final 누락, 수동 수정 후 미commit, 선택 데이터 미반영 상태를 정확히 검사
- 미완료 주요 변수와 데이터 세트를 안내하고 해당 위치로 자동 이동
- 무작위 예측 계열을 세션에 고정해 기간 변경 시에도 같은 결과 유지
- 가격 데이터에 상승·하락 변동성을 포함하고 예측 범례를 예측가로 통일
- 주요 변수 및 가격 그래프의 예측 시작점에 예측시점 라벨 표시
- 선택값만 달라진 경우 첫 예측 시도에 한 번 안내하고 재시도 시 committed final 기준으로 진행
- 경고창에 한 번만 실행되는 주의 강조 애니메이션 적용


[Version 2.1]
파일명: item_selection_v2.1.py

[기능 업데이트]
- 가격 예측 결과에서 주요 변수 final 그래프와 품목 가격 예측 그래프를 좌우 비교 카드로 표시
- 수요·공급·원재료·투자·거시경제 버튼으로 왼쪽 주요 변수 그래프 전환
- 공통 1년·2년·3년 기간 선택을 두 그래프에 동시에 적용
- 오른쪽 데이터셋 비교 패널에서 이전 데이터셋1과 현재 데이터셋2의 표시 상태 선택
- 데이터셋 저장 버튼으로 현재 commit 및 가격 예측 결과를 데이터셋1에 세션 저장

[개선·수정 패치]
- 왼쪽은 선택 데이터 세트의 과거 base와 committed final, 오른쪽은 실제가와 예측가 표시
- 가격 예측 결과를 검은 세로 막대가 있는 공통 소제목과 하나의 테두리 영역으로 구성
- 두 그래프의 높이·제목 위치·카드 구조를 통일
- 그래프 높이를 285px로 조정하고 콘텐츠에 맞춰 카드 높이를 자동 결정
